# 📝 리뷰 모아 (Review Moa)

### 1. 프로젝트 한 줄 소개

> **파편화된 PR 피드백을 모아 연속적인 성장을 돕는 크루 맞춤형 리뷰 학습 플랫폼 🚀**

### 2. 프로젝트 사용자는 누구인가요?

현재 주요 타겟은 **우아한테크코스 8기 크루(리뷰이)와 리뷰어**이며, 추후 서비스 안정화에 따라 전체 기수로 대상을 확장할 계획입니다.

**👩‍💻 크루 (리뷰이)**

* **내 리뷰 모아보기:** 파편화된 PR 코멘트들을 뒤적일 필요 없이, 자신이 받은 리뷰를 정리된 '카드' 형태로 한눈에 파악합니다.
* **동료 학습 (Peer Learning):** 다른 크루들이 받은 다양한 리뷰 카드를 열람하며 간접적으로 학습하고 인사이트를 얻습니다.

**🧑‍🏫 리뷰어**

* **리뷰이 피드백 이력 조회:** 리뷰를 진행하기 전, 해당 크루가 이전 미션들에서 어떤 피드백을 받았는지 한눈에 파악합니다.
* **맥락 기반의 맞춤 리뷰:** 리뷰이가 자주 반복하는 실수나 개선해야 할 취약점을 미리 인지함으로써, 더욱 효과적이고 실질적인 도움을 주는 리뷰를 제공할 수 있습니다.

### 3. 어떤 목적으로 만들어졌나요?

우테코 미션을 진행하다 보면 수많은 PR 코멘트 속에 리뷰가 흩어져 있어, 이를 한눈에 파악하거나 다음 미션에 반영하기가 매우 번거롭습니다. '리뷰 모아'는 이러한 크루들의 실질적인 불편함을 해소하고, 코드 리뷰의 효용성을 극대화하기 위해 탄생했습니다.

**📌 주요 목적**

* **흩어진 피드백의 통합 및 활용:** 미션 종료 후 자신이 받은 리뷰들을 한곳에 자동 정리해 줍니다. 이를 통해 이전 피드백을 쉽게 파악하고, 다음 미션 진행 시 누락 없이 스스로 적용할 수 있도록 돕습니다.
* **손쉬운 동료 피드백 열람:** 복잡한 원본 PR 링크를 찾아 헤맬 필요 없이, 다른 크루들이 받은 유의미한 피드백을 깔끔한 '카드' 형태로 편리하게 탐색할 수 있습니다.
* **리뷰어를 위한 히스토리 제공:** 리뷰어가 리뷰이의 이전 피드백 이력을 빠르게 파악할 수 있게 하여, 이전 미션의 맥락까지 고려한 더욱 효과적이고 실질적인 리뷰를 진행할 수 있도록 지원합니다.

**📊 부가 기능**

* **미션별 리뷰 트렌드 통계:** 각 미션마다 어떤 리뷰 주제(테마)가 가장 많이 언급되었는지 통계로 제공하여, 해당 미션에서 크루들이 공통적으로 집중해야 할 핵심 포인트나 어려워하는 지점을 직관적으로 확인할 수 있습니다.

### 4. 주요 기능은 무엇인가요?

**🗂 리뷰 카드 탐색 및 필터링**

* **다중 조건 검색:** 분야, 크루, 미션, 테마 등 다양한 조건으로 정교하게 필터링하여, 지금 내게 필요한 리뷰 카드만 빠르고 정확하게 찾아볼 수 있습니다.
* **관심 테마 모아보기:** 특정 주제(예: 네이밍, 객체지향 설계, 테스트 코드 등)에 대한 피드백만 집중적으로 모아보며 부족한 부분을 효율적으로 학습할 수 있습니다.
* **원본 PR 바로가기:** 리뷰 카드를 열람하다가 전체 코드의 흐름이나 구체적인 문맥이 궁금해지면, 클릭 한 번으로 원본 PR 페이지로 즉시 이동할 수 있습니다.
* **랜덤 카드 조회**: 다양한 리뷰 카드를 무작위로 탐색하며 예상치 못한 새로운 인사이트를 얻고 시야를 넓힐 수 있습니다.

**📊 미션별 리뷰 통계**

* **핵심 테마 랭킹:** 각 미션에서 가장 많이 언급된 리뷰 테마의 순위를 제공합니다. 이를 통해 해당 미션의 주요 학습 포인트가 무엇이었는지, 전체 크루들의 피드백 트렌드를 직관적으로 확인할 수 있습니다.
* **크루별 발전률 순위**: 크루들의 발전률을 순위 형태로 확인할 수 있어, 서로 긍정적인 자극을 주고받으며 성장에 대한 동기를 부여할 수 있습니다.

### 5. 다른 서비스와 차별화되는 본인 서비스의 강점은 무엇인가요?

> **"우리 서비스의 가장 큰 차별점은 단발적인 PR 관리가 아닌, 피드백의 '자산화'와 '연속적인 성장'에 초점을 맞춘 학습형 리뷰 플랫폼이라는 점입니다."**

기존 시장에 존재하는 코드 리뷰 도구들이 주로 '현재 진행 중인 PR을 얼마나 빨리 병합(Merge)할 것인가'에 집중한다면, 저희 서비스는 다음과 같은 **세 가지 명확한 차별성**을 가집니다.

* **파편화된 리뷰의 '지식 자산화' (집단 지성 활용)**
* 코드 문맥을 몰라도 누구나 타인의 피드백을 직관적으로 열람할 수 있도록 리뷰를 '카드' 형태로 구조화했습니다. 원하는 테마별로 피드백을 쉽게 필터링할 수 있는 강력한 지식 저장소 역할을 합니다.


* **미션 기반의 '연속적인 성장' 지원**
* 이전 미션에서 받았던 리뷰들을 한눈에 모아볼 수 있게 하여, 크루들이 다음 미션을 진행할 때 스스로 피드백을 쉽게 반영하고 적용할 수 있도록 돕습니다.


* **데이터 기반의 깊이 있는 리뷰와 통계 인사이트**
* 리뷰어는 리뷰이의 이전 피드백 기록을 참고하여 더욱 맥락에 맞는 실질적인 리뷰를 제공할 수 있습니다. 또한, 미션별 핵심 리뷰 통계를 통해 크루들이 공통적으로 겪는 어려움과 트렌드를 전체적으로 파악할 수 있습니다.



**🎯 결론**
단순히 협업 프로세스를 자동화하는 툴을 넘어, 코드 리뷰에서 발생하는 데이터를 가공해 리뷰이와 리뷰어 모두의 성장을 가속화하는 '리뷰 데이터 중심의 교육 및 성장 플랫폼'이라는 것이 저희 서비스만의 독보적인 강점입니다.
